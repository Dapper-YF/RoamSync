# Reviewed place photographs

These JPEGs are licensed third-party photographs, **not** covered by any license
for RoamSync application code. See `../reviewed_images.json` for the author,
original Commons file, selected license URL, changes, original SHA-1, local
SHA-256 and exact associated AMap POI identity for every file.

Individual review dates are recorded per photo in the catalog. Local variants are resized and
JPEG-compressed; cover presentation may crop the view. CC BY-SA adaptations
remain under the specified original CC BY-SA license. CC0 files retain their
public-domain dedication. Attribution and license links appear beside the image
in the application; retain that information when reusing or redistributing.

Only reviewed files are served. There is no runtime third-party image proxy,
scraper, automated Commons search, or cache of restricted AMap photographs.

The 2026-10-24 Kuanzhai Alleys addition and catalog license/digest recheck are
documented in `docs/evidence/conversation-itinerary-20261024/MEDIA_AUDIT.md`
from the repository root.
