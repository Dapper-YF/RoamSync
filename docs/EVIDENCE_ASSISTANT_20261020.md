## 结论与范围
VERIFIED：基于 af6b408，复用 TravelAssistant、AssistantSession、现有 SSE 与 Place 身份；没有新增旅行业务模型、迁移或写入权限。限定为可取得证据的个人项目版本，不宣称具有大众点评/美团完整评论、实时排队、团购或商业级推荐能力。

## 实现
- assistant_research.py：已有目标路由/InformationNeed 之后进行有界只读判断；承接最近用户表达、界面城市及已核实地点。城市未知才追问，不推测 GPS。具体分店先查完整名称，必要时一次品牌查询，再按分店身份严格过滤。
- assistant_places.py / place_content：高德 V5 business 字段补充参考评分、人均、标注时间、地点标签；沿用原有 ID、缓存及地点详情/地图。旧 V3 搜索不变。
- external_facts.py：Tavily Extract 读取本轮搜索得到的公开 HTTPS 页面。标题和正文分别检查地点身份；不绕过登录、验证码或访问限制。
- 来源附 source_id/place_id/read_level/retrieved_at/excerpt/support_quotes。模型引用服务端生成的片段编号，URL 和门店字段由服务端提供；错误编号、错分店、无依据数字和仅凭 POI 编出的评论/排队结论被过滤。非数字文字的语义蕴含仍依赖模型，不是完整事实证明器。
- 每轮最多 3 地点、每地点最多 2 网页、网页并发 2；地点查询串行以适应个人 Key QPS。检索阶段预算 45 秒，超时保留已取得结果；模型生成另受现有 Provider 超时限制，不能称总响应时间保证为 45 秒。阻塞 HTTP 线程在请求超时前可能继续收尾。
- 新只读链在取得会话行锁前完成网络读取。保存前以会话快照比较拒绝迟到结果，同 message_id 重试幂等。普通咨询不写 Trip；原 Accept/版本保护路径不变。其他既有路径持锁风险未在本轮全盘修复。
- web_search 可选元数据兼容旧消息。正文使用 [n] 锚点，参考链接区区分正文/搜索摘要/高德参考。真实工具进度进入独立“思考过程”，正文开始自动折叠，可手动展开并随消息恢复；不展示私有推理。
- 图片最多 3 张。检索图只采纳本轮明确主题，通用火锅图标为参考图，不贴具体分店身份；已有审核过的 Commons 照片保留作者/许可/修改说明。检索热链不等于获得任意商业使用权，不新增图片下载器。图片失败仅隐藏图片。
- 正式文本通过证据编号检查后按句发送，复用前端缓冲。不是逐字假动画；模型结构化生成期间展示实际检索/整理状态。
