# 目的地检索、选点依据与候选拒绝修复

本次修复针对空行程未调用网页搜索、泛化高德 POI 搜索主导选点、拒绝候选后仍受旧方案影响，以及全程需求被页面选中日期限制的问题。

## 行为

- Web Search 不再依赖候选地点或天气坐标。天气查询失败不会丢弃搜索结果。
- 新建、整体重规划、增加和替换地点都会先研究目的地。已有候选地点不再阻止新研究。
- 研究模型从网页标题、摘要中筛选代表性景点，再调用高德按具体名称定位；不会把停车场、游客中心或第一个模糊结果当作景点。
- 默认优先用户指定地点和有依据的知名景点。高德评分不等同于知名度。非知名地点必须说明与用户偏好相关的独特价值。
- 研究返回的引用下标必须有效，引用文本中必须实际出现景点名称。网页仍是检索摘要，不能据此保证营业时间、票价、预约或排名已核实。
- 地点选择与路线安排分别承担不同职责：研究解释特色与选择依据；编排器解释当日体验、分区与节奏；现有高德路线和规则校验验证时间、预算、日期及活动保护。
- 指定地点无法唯一定位时明确反馈名称；模型遗漏指定地点时重试一次，仍遗漏则报告具体冲突，不静默替换。
- 当前研究筛选本轮可用候选，正式活动按原有规则保留。已拒绝方案不会作为计划模板，其审批中断被清除，历史中的旧候选回答不再作为新请求依据。
- 整趟旅行包含多个景点的请求不受页面默认日期限制；真正的局部修改会限制模型可选日期。“调整一下”等信息不足的请求仍会澄清。
- 前端隐藏已拒绝的活动预览，明确提示后续按新要求重新规划；候选展示网页来源链接与检索时间，重复校验错误合并显示。

- 独立 PostgreSQL 临时数据库：212 项后端测试通过（2 条既有 Starlette 弃用警告）。测试库与真实接口联调库分离。
- Web：50 项测试通过，ESLint、TypeScript 与 Vite 生产构建通过。
- 新增回归覆盖：空行程搜索、天气失败、明确日期与默认日期、地图精确匹配、引用真实性、旧候选排除、指定地点遗漏、拒绝后下一次规划、搜索认证及前端来源/拒绝展示。
- 真实 Tavily 搜索已成功返回 7 条来源。首次的 401 来自旧凭据；用户更新 `.env` 后，清除启动环境中覆盖 `.env` 的旧变量并重建服务，使新凭据生效。
- 真实联调暴露的搜索连接中断、研究输出截断、高德 QPS 限频已分别增加独立代理/超时及一次重试、使用项目输出额度、连续检索间隔及一次退避。
- “最美S湾”的高德直接检索实际返回了餐馆；这些结果被拦截。新增有网页依据的别名映射，以及 S湾/S弯、村落/景点后缀匹配，理由中披露名称对应关系；没有依据时仍要求明确地点。
- 模型接口此前返回 HTTP 402，正文为 `Insufficient Balance`；保留 `planner_insufficient_balance` 明确提示。用户充值后，已通过真实 Tavily → DeepSeek 研究 → 高德定位 → DeepSeek 编排 → 高德路线 → 规则校验 → 候选待确认的完整链路。
- 真实运行 `86d6a1c0-8099-4bbb-a601-fdab9fc777ac`：2026-10-01 至 10-03 的大理三天行程，8 条网页来源、7 个活动，包含苍洱大道、龙龛码头和按来源对应的磻溪 S 弯。状态 `awaiting_confirmation`，校验 `valid: true`，4 段路线均为高德真实查询（`is_estimated: false`），正式活动数为 0。证据见 [完整联调记录](evidence/live-destination-research.json)。
- 实际联调补充：繁简体地名统一；无效引用被逐条剔除，至少保留一条支持地名的真实引用；用户点名景点增加专项搜索并按 URL 去重；“最美”等修饰名称只有唯一来源匹配才映射，多个地点时仍报告歧义。回归测试覆盖上述边界及专项检索失败保留已有来源。
- 提示调整后，复用上述运行保存的真实研究资料，单独再次调用真实编排模型与地图路线服务：得到三天 9 项活动，喜洲在第二天、双廊/理想邦/小普陀在第三天，6 段真实路线，日期与路线校验通过。此项是使用既有真实研究的编排复查，没有重复运行搜索研究，也没有创建或接受正式方案。证据见 [编排复查](evidence/planning-reason-recheck.json)。
- API、Worker 与 Web 已更新，API `/health/ready` 返回 ready。

## 当前运行限制

DeepSeek 余额恢复，Tavily 新凭据生效，完整候选链路已通过验收。测试活动只在隔离数据库中，未写入用户正式行程。

增加 `TAVILY_PROXY_URL` 与 `SEARCH_TIMEOUT_SECONDS`（默认 30 秒）。本地搜索已使用现有网络代理；模型与搜索的代理分别配置。修改 `.env` 后需要重新创建 API 与 Agent Worker 容器。注意旧 shell 环境变量会优先于 `.env`，应清除相关旧变量后启动。密钥不应写入代码、文档或对话。

搜索认证失败会返回 `planner_search_authentication_failed`；搜索无结果或不可用会返回 `planner_research_unavailable`。这两种情况均不降级为随机高德选点。

规则校验验证时间与约束可行性，并不证明路线最短或所有自然语言理由正确。首轮真实候选中，喜洲至理想邦约 86 分钟的跨岸车程可放入时间窗，但模型曾将同日安排解释为“分日游览”；已收紧编排提示，要求理由与实际日期、顺序、时间及季节一致，不声称未比较过的最优路线。网页内容仍是检索摘要，后续票价、预约、营业及季节性体验需按来源继续核实。

接口依据：[Tavily Search 官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)。
