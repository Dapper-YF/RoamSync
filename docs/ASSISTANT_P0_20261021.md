## 实现

### 可靠性与恢复

`assistant_reliability` 提供请求关联 ID、90 秒咨询工作预算、至多两次回答生成的共享预算，以及只包含允许字段的诊断。模型决策独立最多一次，15 秒上限；生成修复与临时故障重试共用两次额度。请求内 SDK 重试关闭；鉴权/权限/无效参数和内容过滤不自动重试。

记录失败阶段、错误分类/代码、异常类型链、HTTP 状态、finish_reason、耗时和校验字段/类型。默认不保存异常原文、密钥、提示词、完整模型输出或隐藏思考。已完成消息把安全摘要写入原有会话 JSON；进程重启后监控接口仍能返回摘要。SSE 边界错误也记录关联 ID，区分会话冲突和普通请求失败。

严格保留 JSON、来源引用、唯一建议和行程授权校验。正文列表与建议卡片解耦：正文可以介绍多个景点，卡片最多十条重点建议。未完整输出的 JSON 不通过截取前缀发布。第二次生成先发送 reset；失败结果不会保留无效的临时答案。

工具失败保留已取得的地点、起终点或来源；缺少实时资料时明确承认缺口。完全失败显示重试按钮，新请求使用新 message_id；网络断开后的原请求重放仍沿用既有幂等规则。

复合问题保留能力的并集，分别投影只读子问题。地点身份与网页、起终点与路线维持依赖顺序；独立的路线、网页、事实和行程部分并行。多个 Reader 串行访问同一 AsyncSession，读取后提交再调用外部服务。所有部分共享两次回答额度；部分超时或失败保留已经完成的结果。组合回答在组装后统一发布，避免两个流式输出交错；缺少一个目标不阻止另一项已明确的只读查询。

### 能力决策与受控执行

`assistant_capabilities` 在同话题历史、选中地点、浏览城市和当前 Trip 摘要上，选择 direct / lookup / route / facts / itinerary / create / modify / execution / clarify；只读能力为 poi / web / route / facts / itinerary。

直接回答稳定常识、城市景点概览和一般天数建议。具体地址/门店查高德；来源/预约规则/近期活动查网页并按需 Extract；天气/开放先走现有事实解析，超出场馆覆盖时补充网页参考；路线先解析两个端点，再调用原路线适配器。公交不替换成驾车。

参数必须追溯到当前用户、同话题历史、服务器读取的地点或 Trip。允许明确城市前缀加原地点名的组合查询；不允许凭空扩写地点。规范名/供应商别名用于匹配，地铁站和不同分店不能被短名字误绑定。重名返回实际地址和候选卡片，不能取第一个结果。

模型识别意图，服务端验证当前授权片段、否定/假设、目标和版本。创建/修改继续进入原有流程，缺失规划字段由原流程澄清；咨询不生成 PlanningRun 或正式行程。原始用户文本继续作为写入依据，模型提议、网页和历史回复都不授予写权限。既有 UI 采用/简单安排编辑/草稿入口保留原专用处理器。

`assistant_turn` 先读取快照并结束事务，再进行网络工作；上下文 Reader 的 SELECT 也在模型/事实调用前提交。结束后重新加锁、重读会话并比较快照，迟到结果不能覆盖新消息；重复 message_id 不重复追加或生成。请求内缓存焦点地点读取。无 context 的旧客户端也使用同一咨询管线，并保留独立 legacy 历史范围。

### 接口与兼容

- 原消息 API 和 SSE 事件保留。消息增加可选 `execution_summary`：version、correlation_id、answer_status（complete/partial/failed）、answer_attempts、duration_ms、selection、events。
- 监控 `/api/v1/agent-monitor/sessions/{session_id}/messages/{message_id}` 合并进程内事件与持久化摘要。
- SSE error 可选增加 code / correlation_id；会话冲突显示明确的重新读取提示。旧客户端可忽略新字段。
- PlaceView 增加供应商 aliases，默认空列表。旧消息缺少上述字段可正常读取。
- `ASSISTANT_SEMANTIC_TOOLS=true` 为默认配置；Compose 为 API/Worker 传递该开关。设为 false 并按正式脚本重新启动可退回原咨询分派，完整回滚仍使用备份镜像与源文件。
- 无数据库迁移，无第二套 Trip/规划状态，无自动采用方案。本轮不扩展自动配图策略。

网页内容仍是参考材料，不自动成为已核实实时事实。网页回答只选择当前检索的已有片段 ID 并由服务端展示原文和来源；保留页面中观察到的日期，当前问题明确提示适用时效尚未核实。不能将旧公告、摘要或普通游记变成当天预约/营业保证。

## 保留的限制

历史故障缺少原始诊断，不能证明唯一原因。模型仍可能给出多余建议或有偏差的常识，工具选择和日志通过不代表全面内容质量通过。网上评价不等于完整评论共识，普通网页不能证明现场状态；同名地点、公交覆盖与缺少官方当前公告会明确澄清或给出 partial。大范围行程规划继续由既有异步工作流负责，不受咨询 90 秒生成预算替代。
