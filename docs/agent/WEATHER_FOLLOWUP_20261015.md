问题：截图原句“所以南昌今天会不会下雨啊”的词法提取结果为“所以南昌”，
地点接口正确拒绝了这个不存在的城市名称。前轮标准问句测试没有覆盖这种口语表达。

修复：剥离句首话语连接词并修正“那/那么”的匹配顺序，原句直接查询南昌。

多地点澄清，模型失败/格式错误/幻觉地点仍不发布预报。服务超时等故障不触发模型“修复地名”。
