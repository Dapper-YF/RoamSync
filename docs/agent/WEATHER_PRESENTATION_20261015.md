# 天气回复改为先概括、按需展开

2026-10-15，正式目录 E:\Study\RoamSync，已部署 API、Worker 和 Web。

原问题：普通“南昌今天会下雨吗”被直接渲染为十几行逐小时记录和内部新鲜度术语。
现在默认先回答降雨可能性与简短建议，再给出较容易下雨的相邻时段和概括温度范围。
明确询问温度时先答温度；明确询问降水概率才列各小时概率范围；逐小时/详细预报请求仍保留明细。

这次修改的是现有服务端事实呈现，不新增天气生成模型或外部请求。
概率措辞分档只用于个别小时，不计算或声称全天降雨概率，不推断大雨/暴雨。
温度范围向外取整，并标为“约”。只有相邻且已核验的小时可合并为时段；缺失小时不会被跨越。
部分结果明确注明缺失，失败/过期/冲突继续返回无法核实。完整小时数据、来源和新鲜度仍保存在原结构里。
